IOCs on Virtual Machines#

As of February 2026, most IOCs at BMM are running on centrally maintained virtual machines. The prior IOC server, xf06bm-ioc2, is still there and can be fallen back upon should that be needed.

This section documents which IOC is running on which VM server.

Detectors: xf06bm-det-ioc1#

IOC Name

Purpose

eiger-det1

Eiger4 area detector

mythen-det2

Mythen strip detector

simDetector

simulated detector (deprecated)

xs3-4-1

XSpress3X with calibration for the 4-element detector

xs3-7-1

XSpress3X with calibration for the 7-element detector

xs3-8ch

generic XSpress3

Note

The Pilatus100k IOC needs to move from xf06bm-ioc1 to xf06bm-det-ioc1
